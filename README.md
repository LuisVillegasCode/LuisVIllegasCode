## Proyectos seleccionados

### [UNIMap](https://github.com/LuisVillegasCode/Proyecto-de-Software-UNImap)

Herramienta en Python para descubrimiento de hosts, escaneo de puertos y servicios mediante Nmap, clasificación inicial de riesgos y generación de reportes en HTML, CSV y TXT.

### [AccessTrust IAM Lite](https://github.com/LuisVillegasCode/AccessTrust-IAM-Lite)

MVP académico para gestionar solicitudes y accesos temporales a recursos digitales. Incluye roles, políticas de acceso, credenciales temporales y mecanismos de auditoría.

### [OSR-ViT](https://github.com/LuisVillegasCode/proyecto_ids_vit)

Investigación aplicada a detección de intrusiones mediante Vision Transformers y reconocimiento open-set, con perfiles de Mahalanobis para identificar tráfico fuera de distribución.

### [IDS ligero para redes OT](https://github.com/LuisVillegasCode/IDS-BPSO-Modbus)

Experimento de selección de características con BPSO y Random Forest para reducir el costo computacional de un IDS aplicado a tráfico de entornos OT.
